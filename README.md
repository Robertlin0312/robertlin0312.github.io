# Roubert — 個人網站

網址：https://robertlin0312.github.io/

## 檔案
- `index.html` 首頁（作品牆＋About）
- `work/index.html` 作品內頁版型（自動讀取作品資料）
- `assets/works.js` **所有作品資料都在這裡**，新增作品看檔案最上面的說明
- `assets/site.css` 樣式　`assets/wall.js` 作品牆排列
- `works/` 放每件作品的圖片，一件作品一個資料夾

## 新增作品
1. 建 `works/作品代號/`，放 `cover.jpg` 和內頁圖（圖片長邊建議 2000px 以內、JPG）
2. 在 `assets/works.js` 的清單最前面加一筆
3. GitHub Desktop → Commit → Push
